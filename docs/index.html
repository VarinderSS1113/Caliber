How it works

From a real object to a printable file

Caliber reconstructs the geometry, cleans it up, scales it to a real measurement, and exports a sliceable model — automatically.

Capture or import

Film a slow orbit, snap a few photos, or drop in an existing .glb / .obj / .stl.

Reconstruct

It routes your object to the right engine and rebuilds the 3D geometry.

Clean & scale

Auto de-junk, fill holes, make watertight, and size it to your one measurement.

Preview & export

Spin it in 3D, then download STL, OBJ, PLY, or 3MF.

Two engines, one workflow

The right tool for every object

Matte and round objects are measured locally for free. Shiny, dark, or symmetric objects — the ones photogrammetry can't do — use a generative model with your own key.

LOCAL · FREE · OFFLINE

Photogrammetry

Apple Object Capture measures real geometry from a video, right on your Mac's GPU.

  • Best for matte, textured, or round objects
  • Dimensionally honest, captures the true shape
  • Runs entirely on-device — nothing uploaded
CLOUD · BRING YOUR OWN KEY

Generative

A hosted AI model rebuilds a coherent object from photos — immune to the gloss and symmetry that break photogrammetry.

  • Best for shiny, dark, metallic, or symmetric objects
  • Multi-view (front/back/left/right + top/bottom) for fidelity
  • You bring your own provider key and pay a few cents per model

What's new

Release notes

Caliber 1.1June 2026
  • Scan-to-CAD (beta) — detects planes, cylinders, cones/tapers, holes & domes and exports them as editable parts (OBJ) or real STEP B-rep solids you can modify in Fusion/SolidWorks
  • STEP & “editable parts” exports added (on top of STL, OBJ, PLY, 3MF)
  • Two-point measurement — click two points on the finished model to set exact real-world scale
  • Native macOS app — ships as Caliber.app in a drag-to-Applications .dmg, with its own name & icon, no terminal or browser tab
  • Mix video + photos for the local engine; feed a video to Cloud and Caliber pulls the sharpest frames automatically
  • Smart capture guidance — file-aware engine tips, photo-naming for Cloud (Hunyuan vs TRELLIS), and a full visual capture guide
  • Friendlier results — native Save dialog, Clear / Start-over, and plain-language errors
  • Security pass — per-launch session token, 3D libraries vendored locally (no CDN), pinned build deps, hardened key storage
  • Request-a-feature & bug-report links in the app and site
Caliber 1.0June 2026
  • Local photogrammetry engine (Apple Object Capture)
  • Generative cloud engine with bring-your-own-key
  • Auto engine routing (matte/round → local, shiny/symmetric → cloud)
  • One-measurement real-world scaling (diameter + height pinning)
  • Automatic watertight cleanup & hole-filling
  • Surface-of-revolution rebuild for round objects
  • Live 3D preview & export to STL, OBJ, PLY, 3MF
  • Import & clean existing .glb / .obj / .stl
  • Security-hardened local server (loopback-only, host/origin checks)
  • Full whitepaper & capture/lighting guide included
