# Examples gallery images

Drop your before → after images here with these exact filenames, and they'll appear
on `examples.html`. Photos can be `.jpg`; model screenshots can be `.png` (or `.jpg`).

| Filename | What it is |
|---|---|
| `app-import.png`      | screenshot of the app's import / engine panel (left side) |
| `app-result.png`      | screenshot of the app's preview / export panel (right side) |
| `taillight-photo.jpg` | photo of the real tail-light housing |
| `taillight-model.png` | screenshot of the reconstructed mesh |
| `bottle-photo.jpg`    | photo of the real supplement bottle |
| `bottle-model.png`    | screenshot of the STEP cylinder in Fusion |
| `porsche-photo.jpg`   | photo of the die-cast Porsche |
| `porsche-model.png`   | screenshot of the reconstructed car mesh |

To add a new example: drop two images here, then add one `<article class="ex">…</article>`
block in `docs/examples.html` (copy an existing one and change the `src`, title, and tags).
